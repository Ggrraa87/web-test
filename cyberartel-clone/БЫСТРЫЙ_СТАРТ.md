## 🎯 ЗАПУСК ЗА 3 ШАГА

### Шаг 1: Установите Docker (если еще нет)

**Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install docker.io docker-compose -y
sudo systemctl start docker
sudo usermod -aG docker $USER
```

**macOS/Windows:**
Скачайте Docker Desktop: https://www.docker.com/products/docker-desktop

### Шаг 2: Перейдите в папку проекта
```bash
cd /home/user/web-test/cyberartel-clone
```

### Шаг 3: Запустите сайт
```bash
# Вариант A - Простой скрипт:
./start.sh

# Вариант B - Docker Compose:
docker-compose up -d

# Вариант C - Docker напрямую:
docker build -t cyberartel .
docker run -d -p 8080:80 --name cyberartel cyberartel
```

### ✅ Готово! Откройте браузер:
```
http://localhost:8080
```

## 🔧 ИЗМЕНЕНИЕ ПОРТА

По умолчанию сайт на порту **8080**. Чтобы изменить:

### Редактируйте docker-compose.yml:
```yaml
ports:
  - "3000:80"  # Измените 8080 на любой порт
```

Затем:
```bash
docker-compose down
docker-compose up -d
```

## 🐛 РЕШЕНИЕ ПРОБЛЕМ

### Проблема: "Cannot connect to Docker daemon"
**Решение:**
```bash
sudo systemctl start docker
sudo usermod -aG docker $USER
# Перелогиньтесь
```

### Проблема: "Port 8080 is already allocated"
**Решение 1** - Измените порт в docker-compose.yml на другой (например, 3000)
**Решение 2** - Остановите процесс на порту 8080:
```bash
sudo lsof -i :8080
sudo kill -9 <PID>
```

### Проблема: "Permission denied"
**Решение:**
```bash
sudo chown -R $USER:$USER .
chmod +x start.sh stop.sh
```

### Проблема: Сайт не открывается
**Проверьте:**
```bash
docker-compose ps  # Контейнер должен быть "Up"
docker-compose logs  # Смотрите ошибки
```
