## 📥 КАК ЗАГРУЗИТЬ И ИСПОЛЬЗОВАТЬ

### Шаг 1: Скачайте изображения
1. Перейдите на Unsplash/Pexels
2. Найдите подходящее изображение
3. Нажмите "Download" (бесплатно)
4. Сохраните на компьютер

### Шаг 2: Переименуйте файлы
Переименуйте скачанные файлы согласно структуре выше:
```bash
# Пример:
unsplash-gaming-pc-123456.jpg → pc-s-class-1.jpg
pexels-computer-789012.jpg → pc-b-class-1.jpg
```

### Шаг 3: Скопируйте в проект
```bash
# Скопируйте файлы в папку images/
cp ~/Downloads/pc-s-class-1.jpg /home/user/web-test/itsales-clone/images/
cp ~/Downloads/pc-b-class-1.jpg /home/user/web-test/itsales-clone/images/
# и так далее...
```

### Шаг 4: Пересоберите Docker
```bash
cd /home/user/web-test/itsales-clone
docker-compose down
docker-compose up -d --build
```

## 🎨 РЕКОМЕНДАЦИИ ПО СТИЛЮ

### Цветовая схема сайта:
- **Основной:** Черный (#000000, #171717)
- **Акцент:** Красный (#E60606, #FF0000)
- **Текст:** Белый (#FFFFFF)

### Идеальные изображения:
✅ Черный корпус с красной подсветкой
✅ RGB освещение (красный/розовый/фиолетовый)
✅ Стеклянные панели
✅ Жидкостное охлаждение
✅ Неоновые акценты
✅ Темный фон

### Избегайте:
❌ Яркий белый фон
❌ Слишком яркие/неоновые цвета (кроме красного)
❌ Беспорядок в кадре
❌ Низкое качество (менее 400px)

## 🚀 БЫСТРЫЙ СТАРТ (3 минуты)

Минимальный набор для улучшения сайта:

1. **Одно изображение для каждого класса ПК** (6 штук)
   - Поиск: "gaming pc" на Unsplash
   - Выберите 6 разных вариантов
   - Переименуйте: `pc-b-class-1.jpg`, `pc-e-class-1.jpg` и т.д.

2. **Три изображения для портфолио** (3 штуки)
   - Поиск: "custom pc build" на Unsplash
   - Выберите самые красивые
   - Переименуйте: `portfolio-1.jpg`, `portfolio-2.jpg`, `portfolio-3.jpg`

3. **Скопируйте в проект и пересоберите:**
```bash
cd /home/user/web-test/itsales-clone
# скопируйте ваши файлы в images/
docker-compose up -d --build
```

**Готово!** Ваш сайт будет выглядеть профессионально! 🎉
